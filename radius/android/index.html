Radius for Android has no internet permission: it cannot send anything anywhere. Check it yourself after installing, in Settings › Apps › Radius › Permissions.

Install it

You don't need Developer options or USB debugging — only permission for your browser to install this one app.

  1. Download. Tap the button above on your phone. If Chrome says the file might be harmful, tap Download anyway (Chrome says that about every app that isn't from the Play Store).
  2. Open it. Tap the finished download (or find Radius-0.5.1.apk in Files › Downloads).
  3. Allow this source once. Android asks whether your browser may install apps: tap Settings, turn on Allow from this source, then go back.
    On Samsung phones the same switch is in Settings › Apps › ⋮ › Special access › Install unknown apps › Chrome (or Samsung Internet, or My Files).
  4. Install. Tap Install. Google Play Protect scans the app first; if it asks, choose Install anyway.
  5. Turn the switch back off if you like (step 3). Radius keeps working.

Set it up

  1. Open Radius, add a zone, and turn on Monitoring.
  2. Allow location Precise, then Allow all the time — that lets Radius warn you with the screen off.
  3. Allow notifications, and set battery use for Radius to Unrestricted. Samsung: also Settings › Battery › Background usage limits › Never sleeping apps → add Radius.
  4. Get the street pack for your region: Settings › Streets › Get street packs.

Updates

Download the newer APK from this page and install it over the old one; your zones and street packs stay. Every version is signed with the same key, so Android accepts it as an update.
